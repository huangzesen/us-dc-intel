# NZ · 新西兰数据中心查询方法论（Datacenter Discovery & Audit Methodology）

> 目的：为新西兰数据中心枚举提供「RMA 资源许可 + 建筑许可 + 电力/电网 + 云区域 + 政府认证 + 运营商官网」六线并联的查询框架。新西兰**没有全国性数据中心许可注册库**，设施/项目枚举主要是**《资源管理法》（RMA）资源许可（resource consent）搜索**+议会层面建筑许可/物业档案跟进；大型项目还会出现在 **EPA fast-track consenting** 与 **环境部（MfE）Fast-track Approvals 项目页**。规划单位通常是**地方/单一管理局（territorial/unitary authority）**而非仅 repo 区域。**电力是高收益独立信号**：Transpower 公开 New Connection Enquiries 仪表盘与 Te Kanapu 数据中心洞见。官方云源在新西兰异常有用：Microsoft New Zealand North 已于 2024-12 开放（奥克兰），AWS Asia Pacific (New Zealand) `ap-southeast-6` 3 AZ 于 2025-09 开放，NZ Digital Government 的 **Public Cloud Data Centre Certification (PCDCC)** 页点名已认证设施。当前可见活动集中于**奥克兰**（超大规模/托管/云区域）、**Waikato/哈密尔顿**（Datacom Kapua）、**Southland/因弗卡吉尔-Makarewa**（Datagrid 超大规模/AI 园区许可链）、**Canterbury/基督城**与**大惠灵顿**（电信/企业/边缘）。本 skill 汇总两份探索报告（官方管线 + 行业发现），供新西兰探索与复核批次使用。

## 核心结构事实（框定每次搜索）

1. **无全国注册库，走 RMA 资源许可**：搜索 `data centre`/`data center`/`datacentre`/`server hall`/`hyperscale`/`GXP substation`/`substation`/`diesel generators`/`backup generators`/`cooling`/`industrial or trade activity`/`discharge of contaminants` + 运营商/SPV 名；许可文件可用宽泛规划语言而非「data centre」类别。**公开可见性不均**：MfE 指引说明 notified consents 公开，但许多数据中心申请可为 **non-notified**；用议会开放数据/物业门户、LGOIMA 请求、物业档案与会议纪要补足。
2. **规划单位是地方/单一管理局**：奥克兰是单一管理局；Southland 项目可能需要 Southland District Council 土地用途许可 + Environment Southland 区域许可 + Invercargill City Council 相关工程批准。每个 region 先映射到 city/district councils 与 regional councils。
3. **生命周期词（保守计数）**：`site selection` < `pre-application meeting` < `fast-track referral / listed project` < `resource consent lodged` < `publicly notified / limited notified / non-notified` < `decision / consent conditions` < `building consent` < `earthworks / enabling works` < `grid investigation / connection agreement` < `commissioning` < `certified / operational`。状态：**Operational**=运营商官方设施页/GCDO 认证/议会完工合规/强运营商公告；**Approved/permitted**=议会或 EPA 资源许可决定/条件/fast-track 批准；**Proposed/planned**=已提交许可/fast-track 申请/运营商开发页/Transpower enquiry；**Lead only**=云区域/Transpower 聚合管线/海外投资批准/目录/无一手文件的媒体。
4. **电力是高收益独立信号**：Transpower Connections hub https://www.transpower.co.nz/connections + New Connection Enquiries 仪表盘 https://experience.arcgis.com/experience/97d4604079b545448280423f9269b9ea（含 load/demand 类别，仅作线索）+ Te Kanapu data centres insights PDF（官方需求方法论与聚合场景）+ grid connection process（小型连接 <18 个月，大型复杂 >3 年）；Electricity Authority https://www.ea.govt.nz/、Commerce Commission electricity lines https://comcom.govt.nz/regulated-industries/electricity-lines。区域配电公司按区 pivot：奥克兰=Vector/Counties Energy/Northpower；Waikato=WEL Networks/Waipa/Powerco；大惠灵顿=Wellington Electricity/Electra/Powerco；Canterbury=Orion/MainPower/Alpine/Ashburton；Southland=PowerNet/Electricity Invercargill/Transpower。**能量字段分列**：grid/enquiry MW、contracted connection capacity、building electrical load、IT load、generator backup capacity、实际年耗，互不换算。
5. **云区域 = 区域存在性，非精确地址**：Azure `New Zealand North`（newzealandnorth，奥克兰，2024-12-12 开放 https://news.microsoft.com/en-nz/2024/12/12/new-zealands-first-hyperscale-cloud-is-open-for-business/）；AWS Asia Pacific (New Zealand) `ap-southeast-6` 3 AZ（2025-09-01 开放 https://aws.amazon.com/blogs/aws/now-open-aws-asia-pacific-new-zealand-region/）；Google 2022-08 宣布新西兰区域（须在 Google locations 页核实现时状态）；Oracle 官方区域清单**无新西兰区域**；TEAM Cloud 用 Oracle Alloy 声明两个北岛主权区域（服务地理 A，设施推断 B）。
6. **GCDO PCDCC 是高价值设施线索（A 级）**：https://www.digital.govt.nz/products-and-services/products-and-services-a-z/public-cloud-data-centre-certification-pcdcc/certified-pcdc-facilities-and-areas 当时列出：CDC Data Centres NZ Limited - Silverdale 1（2025-03-19 认证）、CDC Hobsonville 1（2025-03-19）、Microsoft - AKL02（2025-07-02）。PCDCC 只覆盖政府用认证公有云设施，可能遗漏私有托管/企业/电信/未认证设施，作验证源而非完整清单。
7. **语言与拼写**：英文足够；双拼写 `data centre`/`data center`（新西兰源多用 data centre，美资与全球媒体用 data center）+ `datacentre`/`hyperscale`/`AI factory`/`cloud region`/`sovereign cloud`/`colocation`/`edge centre`/`EdgeCentre`/`exchange`/`carrier neutral`/`submarine cable`/`Tasman Ring`；毛利语变体仅用于广泛网络与利益相关者材料发现：`Aotearoa`、`Te Waipounamu`、`whare raraunga`（数据中心）、`pokapu raraunga`、`raraunga`（数据）、`mana whenua`、`iwi`。

- **C** = 弱线索：数据中心目录、地图站、LinkedIn/社交帖、社区声称、物业投机、无引用摘要。

## 使用流程（探索/复核批次）

1. 读取批次 JSONL（country_code=NZ，divisions=17 regions），按 explorer-industry.md §5 每区域四轮：运营商轮（A/B）→ 媒体轮（B/C）→ 许可轮（A：地方管理局资源/建筑许可 + 区域议会水/排放/土方/海岸/空气许可）→ 基础设施轮（A/B：Transpower/GXP、发电 PPA、光纤/海缆、交换/IX/PeeringDB）。
2. 种子：首轮扫——奥克兰官方轮（GCDO PCDCC → Auckland Council GeoMaps/Open Data → EPA Auckland Surf Park → CDC/Microsoft/AWS/Spark/NEXTDC/Datacom/Digital Island/Qrious pivot）→ Southland 官方轮（Environment Southland Datagrid → Southland DC proposals → MfE Datagrid fast-track → Invercargill CC → Transpower/GXP）→ Waikato/Hamilton 轮（Datacom Kapua → HCC → Waikato Regional → WEL Networks/Transpower）→ Canterbury/大惠灵顿轮 → 其余区域逐议会关键词 + Transpower 仪表盘线索。
3. 验证：计点最低标准=一个 A 级设施/项目源，或一个运营商官方设施页 + 第二个独立 A/B 源；规划中的超大规模项目在把 MW 记为超过 lead 之前，须有议会/EPA/MfE 许可记录或 Transpower/命名电网文件。字段含 division/territorial_authority/regional_council/facility_or_project_name/operator/consent_holder/site_address/legal_description/status/evidence_grade/resource_consent_refs/notification_status/decision_date/facility_type/site_area_ha/gfa/data_halls/it_load_mw/grid_or_connection_mw/backup_generation_mw/water_take_or_cooling/substation_or_gxp/cloud_region_or_certification。
4. 输出：按 world schema 写结果，附证据日期与分级；边缘/电信交换与超大规模/批发分开记录，不聚合 MW 除非站点级原始容量公开。
