## Division layer (future)

The manifest (`world-manifest.jsonl`) defines Djibouti as **6 regions/cities** (`subnational_type = region/city`): **Arta, Ali Sabieh, Dikhil, Djibouti, Obock, Tadjourah**. A future `divisions/` layer will carry per-division discovery/audit skills; a run is incomplete unless all six divisions are searched or explicitly output as `no_projects: true` with query/date notes.
