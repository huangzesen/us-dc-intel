# NL · 荷兰数据中心查询方法论（Datacenter Discovery & Audit Methodology）

> 目的：为荷兰（含荷属加勒比领地）数据中心枚举提供「Officiele Bekendmakingen 许可公告 + Omgevingsloket/DSO 流程 + 省/市空间规则 + omgevingsdienst 环评文件 + TenneT/区域电网证据 + 云区域/运营商官网」六线并联的查询框架。荷兰**没有全国性数据中心注册库**；普查 = **Officiele Bekendmakingen 许可公告**（`zoek.officielebekendmakingen.nl`，市/省/水务局/环境机关发布收到申请、草案决定、已批许可、修正与政策公告——例：Lelystad/Flevokusthaven 申请、Alphen aan den Rijn/Boerhaaveweg 申请、EdgeConneX AMS10 Schiphol-Rijk 二期已批、FalconConnect Plimsollweg 许可修正、Iron Mountain Haarlem 已批）+ **Omgevingswet 框架**（2024-01-01 起生效：`omgevingsvergunning`、`omgevingsplanactiviteit`、`bouwactiviteit`、`milieubelastende activiteit`；旧记录用 Wabo/bestemmingsplan/bouwvergunning/milieuvergunning）+ 电网容量（TenneT + Liander/Stedin/Enexis，netcongestie）+ 官方云/托管页。**国家超大规模空间限制**：Bkl 框架下超大规模数据中心（>10 公顷 且 >=70 MW aansluitvermogen）全国受限，例外区在 **Het Hogeland（格罗宁根）** 与 **Hollands Kroon（北荷兰）**——非例外新提案法律风险高，除非有 2022 前/vested 许可证据。商业市场高度聚集于**阿姆斯特丹/Schiphol/Haarlemmermeer、Haarlem、Middenmeer/Hollands Kroon、Eemshaven/Het Hogeland、Almere/Lelystad/Flevoland、鹿特丹/代尔夫特、埃因霍温**及 NorthC/电信区域节点。本 skill 汇总两份探索报告（官方管线 + 行业发现），供荷兰探索与复核批次使用。

## 核心结构事实（框定每次搜索）

1. **Officiele Bekendmakingen 是国家第一许可搜索（A 级）**：https://zoek.officielebekendmakingen.nl/ 暴露 `Gemeenteblad`/`Provinciaal blad`/`Waterschapsblad`/`Staatscourant`/议会记录与 PDF；HTML 与 PDF 都搜（附件含更丰富许可文本）。高价值样例：Lelystad/Flevokusthaven `Gemeenteblad 2025, 534713`（收到数据中心 omgevingsvergunning 申请）；Alphen aan den Rijn/Boerhaaveweg 10 `Gemeenteblad 2026, 135103`；Schiphol-Rijk/Koolhovenlaan 142 `Provinciaal blad 2026, 11662`（OD NZKG 批准 EdgeConneX AMS10 B.V. 二期建筑活动许可）；Haarlem/J.W. Lucasweg 35 `Provinciaal blad 2025, 5574/2141`（Iron Mountain (Nederland) Data Centre B.V. 建立并运营 Haarlem 数据中心草案/已批许可）；Amsterdam/Plimsollweg 3,13,23 `Provinciaal blad 2025, 12791`（FalconConnect B.V. 许可修正）；Haarlemmermeer 开发容量 `Gemeenteblad 2025, 30669`（市数据中心政策下的可用开发容量公告）。提取：publication_type/number/date、authority/omgevingsdienst、aanvrager、zaaknummer/OLO-nummer/DSO-nummer/kenmerk、地址/地籍宗地/市/省、活动文本（bouwen/milieu/uitweg/strijdig gebruik/omgevingsplanactiviteit）、状态（ontvangen aanvraag/ontwerpbesluit/verleend/geweigerd/wijziging/bezwaar）、检查窗口/上诉期限/MER 要求。
2. **Omgevingswet 许可拆分**：数据中心申请可能拆为技术建筑活动 + 环境活动 + 水排放许可/申报 + 计划外活动/分区偏离 + 备用发电机/燃料罐/电池/氨冷却/变压器设施 + 拆除/树木/道路/消防活动；IPLO 页 https://iplo.nl/regelgeving/regels-voor-activiteiten/milieubelastende-activiteiten-hoofdstuk-3-bal/dienstverlening/datacentrum/ 定义 Bal 3.7.3 的 `milieubelastende activiteit datacentrum`——**冷却水排入地表水热负荷 >50 MW 时须 omgevingsvergunning**。
3. **北荷兰许可常由省级环评机构签发**：**Omgevingsdienst Noordzeekanaalgebied (OD NZKG)** https://odnzkg.nl/aandachtsdossiers/datacenters/ 声明其签发并监督北荷兰数据中心建筑与环境许可；较小数据中心通常归市镇。
4. **国家超大规模空间限制（Bkl）**：Staatsblad 2023, 492（https://zoek.officielebekendmakingen.nl/stb-2023-492.html）+ Bkl 合并文本（IPLO PDF）+ Staatscourant 2022, 5276（临时/预备禁止语境）+ 议会解释（kst-32813-AO、h-tk-20252026-35-3）。操作规则：**>10 公顷 且 >=70 MW aansluitvermogen 为超大规模阈值**；新超大规模提案在命名例外区之外须额外审查：相对 2022-02-16 的申请日期、既有许可权、Bkl 例外、市/省计划符合性；该规则不是一般数据中心禁令，小型托管/企业设施不受限。
5. **电网容量是主要过滤器**：TenneT https://www.tennet.eu/ 是荷兰国家级高压电网运营商；区域运营商 Liander/Stedin/Enexis/Rendo/Westland Infra/Coteq 常发布容量图与拥塞页（北荷兰、Haarlemmermeer/Schiphol、阿姆斯特丹、Hollands Kroon/Middenmeer、格罗宁根/Eemshaven 须显式电网容量验证）；RVO 380 kV North Holland North 扩建 PDF 与 ACM TenneT 投资计划审查信（https://www.acm.nl/system/files/documents/eindbrief-toetsing-investeringsplan-tennet-net-op-land-2026.pdf）作语境。字段分列：`aansluitvermogen`（并网功率）、`transportcapaciteit`（输电容权）、`gecontracteerd vermogen`、`netcongestie`、`hoogspanningsstation`、`transformatorvermogen`、`IT load`——并网纠纷/排队是项目线索，不是施工证明；北荷兰/格罗宁根大项目缺网容可能解释停滞状态。
6. **云区域 = 地理种子，非建筑**：Azure **West Europe = 荷兰**（区域/国家 A，设施级不公开）；Google Cloud **`europe-west4` = Eemshaven**（GPU/TPU 文档暴露 Eemshaven zones 与 De Kooy AI zone）+ **Google 官方数据中心页 Eemshaven/Middenmeer/Winschoten** https://datacenters.google/locations/...（A 设施/园区城市，精确地块仍须许可交叉）；**AWS 无荷兰区域**（仅 Direct Connect/on-ramp 网络存在）；Oracle 查当前官方区域表。
7. **生命周期与状态词（保守计数）**：`locatieonderzoek` < `vooraankondiging`/`ontvangen aanvraag` < `ontwerpbesluit`/`ter inzage` < `zienswijze` < `vergunning verleend` < `bezwaar`/`beroep` < `onherroepelijk` < `start bouw` < `in gebruik genomen`/`operationeel` < `wijziging vergunning`/`uitbreiding`。只有 `vergunning verleend`、`onherroepelijk`、`start bouw` 或更强计为许可/施工证据。状态模型：lead（仅云/运营商/媒体信号）→ policy-enabled（计划/开发容量存在但无命名设施）→ application-received → under-review → permitted → appealed/contested → grid-constrained（有许可但电网阻塞）→ under-construction → operational → expansion/amendment。**避免重复计数**：Amsterdam 品牌设施可能位于 Haarlem/Haarlemmermeer/Aalsmeer/Oude Meer/Halfweg/Diemen；「Rotterdam」品牌的 Colt 在 Roosendaal（北布拉班特）。
