# MR Explorer Industry - Mauritania Datacenter Enumeration

Date: 2026-08-12. Country: **MR Mauritania**. Scope: industry, operator, vendor, directory, and local-press discovery for Mauritanian datacenters, with official verification paths for every lead. Division model: **15 manifest regions**: Eastern Basin, Western Basin, Assaba, Gorgol, Brakna, Trarza, Adrar, Nouadhibou Peninsula, Tagant, Guidimaka, Tiris Zemmour, Inchiri, West Nouakchott, North Nouakchott, South Nouakchott.

Reliability grades:

- **A** = primary source for the claim: AMI, MTNIMA, ARE, ARMP, EIB, EEAS / EU Global Gateway, World Bank project documents, Uptime Institute, SDIN, IMT or official operator facility page.
- **B** = strong secondary or trade press: Data Center Dynamics (DCD), DCmag.fr, Agence Ecofin, We Are Tech, CIO Mag, World Bank blog, established local press when it quotes named officials or project documents.
- **C** = lead-only: DataCenterMap, datacenters.com, datacenterslist, thebuildout.ai, neocloud.asia, consultant SEO pages, generic market reports, social posts, LinkedIn claims, local IT-service marketing pages without facility evidence.

Industry sources are discovery tools. Upgrade a lead only after it is matched to official evidence or an operator page that names a physical facility, site, racks, room, certification, or service location.

## 0. Market Frame

- Mauritania is a **nascent, state-led datacenter market**. The only A-grade public datacenter anchor found in this pass is **Nouakchott Data Hub / Nouakchott National Data Center / Centre d'hebergement de donnees numeriques de Nouakchott** in **West Nouakchott**.
- The Nouakchott Data Hub was inaugurated **8 May 2025**. Official / primary sources confirm: 1,372 m2, 100 racks expandable, Tier III design + constructed facility certification, EUR 15m EIB loan, SDIN owner / infrastructure role, IMT operational role, and national cloud / hosting / backup / continuity / AI-big-data service purpose.
- Everything else should initially be treated as one of four non-DC categories: **telecom / cable landing infrastructure** (ACE / WAC / EllaLink), **IXP / network node**, **institutional server room / compute center**, or **cloud-service procurement**.
- The 2026 MTNIMA EllaLink announcement confirms a new cable landing at **Nouadhibou** and a neutral cable landing station. This is important connectivity context, but it is not a datacenter record without additional compute or colocation evidence.
- No AWS, Azure, Google Cloud, or OCI public cloud region is listed for Mauritania on official region pages. Any "cloud" lead should be interpreted as sovereign / government / telecom / partner-hosted service until proven otherwise.

## 3. Directory and Aggregator Handling

Directory leads are C-grade by default. They are useful for names, addresses, and alternate aliases, but often mix official facts with unverified metadata.

| Directory | What to capture | How to verify |
|---|---|---|
| DataCenterMap Mauritania / Nouakchott | Facility name, operator, address string, claimed tier, city | Match exact name to AMI, EIB, Uptime, SDIN. Use DataCenterMap only as address / alias lead if official sources do not publish street detail. |
| datacenters.com / datacenterslist.com | Facility aliases and operational status claims | Verify against AMI / EIB / Uptime. Do not copy capacity unless sourced. |
| thebuildout.ai | Project profile / summary | Treat as synthesis. Follow its cited sources, then use originals. |
| neocloud.asia and consultant SEO pages | Generic market / service pages | Ignore unless a named local facility appears. Most are generic service pages, not evidence. |
| PeeringDB / IXP directories | RIMIX / IXP nodes and networks | Network-interconnection evidence only. Not a datacenter unless site / host facility is named. |

Directory upgrade workflow:

1. Capture exact name, operator, address, claimed status, claimed tier, rack / sqm / MW claims, and page date if available.
2. Search exact name in AMI, MTNIMA, EIB, EEAS, Uptime, SDIN, and operator sites.
3. Search ARMP / MTNIMA for construction, equipment, maintenance, or migration contracts.
4. Search DCD / DCmag / Ecofin for trade confirmation.
5. If primary support exists, use the primary source in `source_urls` and mention directory only as a secondary address lead. If no primary support exists, keep C or discard.

## 7. Output Discipline

For each candidate:

- Normalize `division` to one manifest name; keep local wilaya and locality in notes.
- Prefer A-grade URLs in `source_urls`; add B/C sources only when they contribute unique facts or discovery context.
- Keep `capacity_mw=null` unless a source gives MW / kW / MVA for the exact facility.
- Record non-MW details such as 1,372 m2, 100 racks, Tier III awards, cable landing, IXP, or cloud-contract amount in `notes`.
- Split facility records from context records: a datacenter, a cable landing station, an IXP, and a government cloud procurement are separate evidence categories.
- Use `no_projects=true` only after official + industry + directory + locality searches are negative and after excluding generic Nouakchott / national results.
