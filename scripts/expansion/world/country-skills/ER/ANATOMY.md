## Division layer (future)

The manifest (`world-manifest.jsonl`) defines Eritrea as **6 regions**: **Anseba; Southern Red Sea; Southern; Gash-Barka; Central; Northern Red Sea**. A future `divisions/` layer will carry per-region discovery/audit skills; searches must combine manifest names with local/common names (Central = Maekel/Asmara; Southern = Debub/Mendefera; Northern Red Sea = Semienawi Keyih Bahri/Massawa; Southern Red Sea = Debubawi Keyih Bahri/Assab; Gash-Barka = Gash Barka/Barentu; Anseba = Keren), and negative searches must be recorded explicitly.
